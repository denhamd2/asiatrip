# familytrip

Family Asia holiday itinerary dashboard (June–July 2026).

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Production build

```bash
npm run build
npm start
```

## Deploy

Hosted on [Railway](https://railway.app) from this repo (`main` branch). Railway runs `npm run build` then `npm start` to serve the Vite static build.
